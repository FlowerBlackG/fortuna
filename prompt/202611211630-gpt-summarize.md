# Effective values in reports

- The web report shows only Effective value in the record table and summary cards. The value column sorts by the effective amount.
- Excel and PDF exports show effective values for record details and totals. When a target currency is selected and some records use another currency, the detail tables include a converted effective value column.
- The frontend calculates each effective value as `amount × effective_rate` and uses the report’s exchange rates when a target currency is selected. The original-currency view groups totals by currency. The report detail and its exports mark totals as partial when a conversion is missing.
