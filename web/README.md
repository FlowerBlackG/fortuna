# Fortuna web

React, hash routing, TDesign, Axios, and ECharts. See the [root README](../README.md) for setup.

- `vp run dev-all-hosts`: development server
- `vp run build`: type-check and build static files
- `vp run lint`: lint and type checks
- `vp run test`: calculation tests
- `vp run test:browser`: Chrome integration flow against running local servers
- `vp run test:regression`: cache/error recovery and chart-value regression checks against Vite
